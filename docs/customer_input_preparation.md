# Customer Input Preparation

## Objective

Prepare encoded customer features for the customer tower of the Two-Tower Neural Recommendation Model.

## Features Used

- FN
- Active
- age
- is_active_member
- receives_fashion_news
- is_active_customer
- club_member_status_encoded
- fashion_news_frequency_encoded
- age_group_encoded

## Validation

- Verified all required columns are present.
- Checked for missing values.
- Saved the prepared input dataset as `customer_model_input.csv`.
